# Голосовий банк

Тут лежать короткі репліки, які повторюються в кожній довгій добірці:

* `intro-<N>.mp3` — «У цьому відео N фактів про Україну. Почнімо.»;
* `fact-<NN>.mp3` — «Факт перший», «Факт другий», …

Текст у них не змінюється ніколи, тож синтезувати їх на кожну збірку немає
сенсу: звучали б так само, але щоразу палили б символи ElevenLabs. Тому кожна
репліка синтезується **раз** і далі просто підставляється.

Згенерувати наперед і закомітити:

```bash
node scripts/build-voice-bank.js 20        # вступ на 2–20 фактів + «Факт 1…20»
node scripts/build-voice-bank.js 20 --force  # перезаписати наявні
git add assets/voice && git commit -m "Голосовий банк"
```

Якщо репліки тут немає, збірка шукає її в папці Drive (`VOICE_FOLDER_ID`, за
замовчуванням та сама, що й для відео — `VIDEO_FOLDER_ID`) під назвою
`voice-<ключ>.mp3`, і лише тоді синтезує. Усе синтезоване одразу лягає на
Drive, тож наступний контейнер уже його не синтезує.
