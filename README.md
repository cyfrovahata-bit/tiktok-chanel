# Слайдшоу-монтажер «Чи Ви Знали?»

Telegram-бот-конвеєр без сервера, повністю на GitHub Actions.

Двічі на день бот надсилає власнику готовий промпт з темою для ChatGPT,
приймає у відповідь 6 фото, монтує з них вертикальне слайдшоу 9:16
(1080×1920) через FFmpeg, генерує через OpenAI назву, опис і хештеги
та повертає 4 чистих повідомлення для публікації в TikTok / YouTube Shorts.

## Як це працює

1. **10:00 та 18:00 (Київ)** — воркфлоу `themes` генерує нову тему через
   OpenAI (звіряючись із базою вже використаних у `state.json`), підставляє
   її у `prompt.template.txt` і надсилає в Telegram. Під повідомленням —
   кнопка **«🔄 Інша тема»**.
2. Ви копіюєте промпт у ChatGPT: він пише сценарій (тексти 6 слайдів),
   далі командами «намалюй перше фото», «намалюй наступне» генеруєте
   6 фото. Боту пересилаєте **текст сценарію** і **6 фото** (можна
   альбомом) — сценарій стане основою озвучки.
3. Воркфлоу `check` запускається за розкладом у робочих вікнах (3 години
   після теми) і читає оновлення:
   - кнопка «Інша тема» → стара тема позначається `rejected`, приходить
     новий промпт з новою темою;
   - сценарій **і** 6 фото разом → монтаж відео з озвучкою + генерація
     текстів → у відповідь 4 повідомлення: **відео / назва / опис +
     хештеги (через порожній рядок) / 3 варіанти музики з TikTok» —
     тексти без зайвих символів, одразу копіюються в TikTok/Shorts.
     Якщо є лише щось одне — бот підкаже, чого бракує, і чекатиме;
   - нічого не надіслано → тихо завершується.
4. Якщо за 3 години фото не прийшли — сесія закривається як `skipped`,
   наступна тема прийде за розкладом.

Весь стан (база тем, offset оновлень, поточна сесія) живе у `state.json`
у цьому ж репозиторії — воркфлоу комітять його від імені
`github-actions[bot]`.

## Налаштування

### 1. Створіть бота

Напишіть [@BotFather](https://t.me/BotFather) → `/newbot` → отримаєте
токен виду `123456789:AA...`.

### 2. Дізнайтесь свій chat_id

Надішліть щось своєму боту, потім відкрийте в браузері:

```
https://api.telegram.org/bot<ТОКЕН>/getUpdates
```

У відповіді знайдіть `message.chat.id` — це ваш chat_id.
Бот ігнорує повідомлення від усіх інших користувачів.

### 3. Додайте секрети репозиторію

GitHub → Settings → Secrets and variables → Actions → New repository secret:

| Секрет | Значення |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен від BotFather |
| `TELEGRAM_CHAT_ID` | ваш chat_id (єдиний дозволений користувач) |
| `OPENAI_API_KEY` | ключ OpenAI (модель `gpt-4o-mini`, копійки за виклик) |

### 4. Увімкніть Actions

Репозиторій має бути **приватним** (безкоштовний ліміт 2000 хв/міс).
Перевірте, що Actions увімкнені (вкладка Actions). Перший запуск можна
зробити вручну: Actions → `themes` → Run workflow.

## Розклад і зимовий/літній час

GitHub cron працює в UTC, тому розклад зафіксовано під **літній** київський
час (UTC+3):

- `themes`: `7 7 * * *` та `7 15 * * *` → ~10:07 і ~18:07 Київ.
- `check`: кожні 5 хв першу годину після теми, далі кожні 15 хв
  (години 7–10 і 15–18 UTC).

Хвилини навмисно «некруглі»: крони на `:00`/`:15`/`:30` ставлять мільйони
репозиторіїв, і GitHub затримує їх найсильніше.

**Двічі на рік** (перехід на зимовий час, UTC+2) треба зсунути всі **години**
у `.github/workflows/*.yml` на +1 (хвилини не чіпати) — або лишити як є
і змиритися зі зсувом на 1 годину.

GitHub cron неточний: фактичний старт зазвичай на 5–20 хвилин пізніше,
а в пікові години затримки бувають значно більші, окремі запуски GitHub
може взагалі пропустити. Якщо тема сильно запізнюється — запустіть
`themes` вручну: Actions → themes → Run workflow.

## Бюджет хвилин Actions

≈26 запусків/день × ~1 хв + 2 монтажі × ~5 хв ≈ **1100–1200 хв/міс** —
влазить у безкоштовні 2000 хв із запасом (≤ 45 хв/добу).

## Озвучка

Кожне відео виходить з безкоштовною українською озвучкою (Microsoft
Edge TTS, голос «Остап»; жіночий — `TTS_VOICE: uk-UA-PolinaNeural`
у `check.yml`). Текст диктора OpenAI складає з надісланого сценарію
слайдів (якщо сценарій не надіслано — за темою), edge-tts синтезує
голос, ffmpeg підкладає його під відео.

Вимкнути — закоментувати `ENABLE_TTS: "1"` у `check.yml`.
Помилка озвучки ніколи не блокує публікацію — відео просто піде без звуку.

## Параметри відео

- строго 9:16, 1080×1920, без чорних смуг (масштаб + кроп по центру);
- 6 слайдів по 4 с, переходи fade 0.5 с, разом ≈ 21.5 с;
- повільний zoom-in (Ken Burns) на кожному слайді;
- аудіо — українська озвучка (див. розділ «Озвучка»); музику в TikTok/Shorts
  додавайте тихим фоном під голос;
- H.264, 25 fps, `+faststart` — грає одразу в Telegram.

## Структура

```
.github/workflows/
  themes.yml          # cron 10:00 та 18:00 Київ — нова тема
  check.yml           # cron у робочих вікнах — обробка оновлень і монтаж
src/
  themes.js           # точка входу воркфлоу themes
  check.js            # точка входу воркфлоу check
  telegram.js         # обгортка Bot API (getUpdates, send*, getFile)
  openai.js           # генерація теми + назви/опису/хештегів
  montage.js          # збірка FFmpeg-команди і запуск
  state.js            # читання/запис state.json + git commit/push
prompt.template.txt   # шаблон промпта з плейсхолдером {{TEMA}}
state.json            # база тем + службовий стан
```

## Локальний дебаг

```bash
export TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=... OPENAI_API_KEY=...
node src/themes.js   # надіслати тему зараз
node src/check.js    # обробити оновлення зараз
```

Поза GitHub Actions `state.json` пишеться локально, але не комітиться.
