Chy Vy Znaly — publishing automation

A private tool that publishes short educational videos to the operator's own social accounts, including one YouTube channel.

What this tool does

The operator runs a small educational channel about Ukrainian geography, history and science. Each video is assembled from still images and a narrated script, then published on a schedule. This tool automates the publishing step: it takes a finished MP4 file that the operator already owns and uploads it to the operator's own accounts with a title, description and tags.

How it uses the YouTube Data API

  • videos.insert — uploads the operator's own finished video to the operator's own channel.
  • channels.list (mine=true) — confirms which channel the authorised token belongs to, so the operator can verify the destination before enabling uploads.

No other endpoint is called. The tool does not search YouTube, does not read other channels, does not collect data about videos or users it does not own, and does not display or embed YouTube content anywhere.

Who can use it

Only the channel owner. The interface is a private Telegram Mini App restricted to a single Telegram account; every request is verified against a Telegram HMAC signature and rejected if the user is not the owner. There is no sign-up, no public interface and no other users.

Scale

Up to three uploads per day — roughly 90 per month. There is no advertising sold inside the content, no resale of API data, and no third-party access of any kind.

Volume of AI-assisted content

Imagery and narration are produced with generative models. Every upload is therefore marked as synthetic content through the API field status.containsSyntheticMedia, so viewers see YouTube's altered-content disclosure. The same disclosure is set on every other platform the tool publishes to.
