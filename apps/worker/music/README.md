# Фонова музика

Покладіть сюди безкоштовні mp3-треки. Файли з цієї папки не потрапляють у git
(крім цього README) — на Railway їх треба або закомітити (приберіть правило
в `.gitignore`), або змонтувати volume.

## Іменування

Щоб worker міг підбирати трек за настроєм сценарію, додайте до назви файлу
одне з ключових слів (українською або англійською):

| Настрій у сценарії | Ключове слово в назві файлу |
| ------------------ | --------------------------- |
| енергійний         | `upbeat` або `energetic`    |
| спокійний          | `calm` або `chill`          |
| загадковий         | `mystery` або `mysterious`  |
| драматичний        | `dramatic` або `epic`       |

Приклади: `upbeat-funky-01.mp3`, `mystery-dark-02.mp3`.
Якщо трек за настроєм не знайдено — береться випадковий mp3 з папки.
Якщо папка порожня — відео рендериться без музики (з попередженням у лозі).

## Де взяти безкоштовну музику

- YouTube Audio Library: https://studio.youtube.com → Аудіотека (безкоштовно, більшість без атрибуції)
- Pixabay Music: https://pixabay.com/music/ (безкоштовно, без атрибуції)
